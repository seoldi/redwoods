GnuBoard5 기반으로 제작한 아파트 분양 홈페이지 커스텀 테마입니다.  
브랜드 스토리, 단지 개요, 평면도, 인테리어, 분양 안내, 커뮤니티 등  
아파트 분양 홈페이지에 필요한 전 섹션을 직접 디자인·퍼블리싱했습니다.

### 주요 구성

**브랜드 & 단지**
- 브랜드 스토리 — 텍스트·이미지 애니메이션 연출
- 단지 개요 (overview) — 사업 개요 및 주요 특징
- 단지배치도 (placement) — 동 위치 및 단지 전체 배치 안내
- 동호수배치도 (layout) — 동호수별 세대 배치 선택 안내
- 평면도 (plane) — A~J 타입 탭 전환 + 이미지 확대
- 시공사소개 (constructor) — 시공사 브랜드 및 주요 시공 실적

**인테리어 & 시설**
- 인테리어 — 50㎡ / 80㎡ / 84A 타입별 내부 갤러리
- 커뮤니티 시설 — 시설 이미지 슬라이더
- 프리미엄 옵션 — 옵션 상품 안내

**분양 안내**
- 분양 안내 (guide 1–9) — 입주자 모집 공고 단계별 구성
- e-모델하우스 — 유튜브 영상 팝업 연동
- 이벤트 / 공지사항 / 최신소식 — GnuBoard 게시판 커스텀 스킨
- 입주자 센터 / 고객센터

**기타**
- 위치 및 교통 (location) — 카카오맵 / 네이버지도 연동
- 브로슈어 — PDF 뷰어 (PDFObject.js)
- 팝업 레이어 — 공지 이미지 팝업 (최대 5개 동시 운용)

### 스택
- PHP / GnuBoard5 커스텀 테마
- HTML5 / CSS3 / JavaScript (jQuery)
- 플러그인: bxSlider, YouTubePopUp, PDFObject, FontAwesome
- 폰트: 나눔스퀘어 (한글), 직접 지정 웹폰트
- 반응형: PC / 태블릿 / 모바일 전 해상도 대응

### 담당 업무
UI/UX 디자인 및 GnuBoard5 테마 퍼블리싱 전담 (1인).  
기획 내용을 바탕으로 Figma 디자인 → HTML/CSS/JS 퍼블리싱 → GnuBoard5 테마 구조 적용 → 서버 세팅 및 운영까지 단독 수행.

A custom GnuBoard5 theme for an apartment pre-sale website.  
Covers every section required for a Korean real estate launch site — brand story, site overview, floor plans, interior gallery, subscription guide, community facilities, and more.

### Features

**Brand & Site**
- Brand story page with animated text and image sequences
- Site overview with project specs
- Site placement map — building locations across the complex
- Unit allocation map — per-unit selection layout by building and floor
- Floor plans — A–J type tabs with zoomable images
- Construction company profile — builder brand and key project portfolio

**Interior & Amenities**
- Interior gallery — per unit type (50㎡ / 80㎡ / 84A)
- Community facilities slider
- Premium options guide

**Sales & Info**
- Subscription guide (9 steps) — structured around the official public notice
- e-Model House — YouTube video popup integration
- Events / Notices / News — custom GnuBoard board skins
- Resident center / customer support

**Utilities**
- Location & access — Kakao Map / Naver Map embed
- Brochure — in-page PDF viewer (PDFObject.js)
- Announcement popups — up to 5 simultaneous layered popup banners

### Stack
- PHP / GnuBoard5 custom theme
- HTML5 / CSS3 / JavaScript (jQuery)
- Plugins: bxSlider, YouTubePopUp, PDFObject, FontAwesome
- Responsive: PC / Tablet / Mobile

### Role
Sole designer and front-end developer. Delivered the full scope solo — Figma design from planning brief, HTML/CSS/JS publishing, GnuBoard5 theme integration, and server deployment.
